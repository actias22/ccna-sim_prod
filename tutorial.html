Cisco CCNA コマンドシミュレーター 使い方ガイド

本シミュレーターは、実際のCiscoルーターおよびスイッチのコマンド操作（CLI）をブラウザ上で極めてリアルに再現した学習ツールです。
このページでは、実機同様に使用できる便利なショートカット機能や、特有の操作方法について解説します。

1. 便利な入力補助機能

コマンドをすべて手打ちする必要はありません。実機と同じ入力補助機能が備わっています。

◆ Tabキーによる自動補完

コマンドの途中まで入力して Tab キーを押すと、残りの文字が自動的に補完されます。入力ミスを防ぎ、素早く設定を行うために必須のテクニックです。

Router(config)# int
(ここで Tab キーを押すと...)
Router(config)# interface

◆ 「?」キーによるコマンド候補の表示

次に何のコマンドや引数を打てばよいか分からない場合、? （クエスチョンマーク）を入力すると、そのモードや文脈で使用可能なコマンドの一覧が表示されます。

Switch(config-if)# switchport ?
  access Set access mode characteristics of the interface
  mode Set trunking mode of the interface
  nonegotiate Device will not engage in negotiation protocol...
  port-security Security related command
  trunk Set trunking characteristics of the interface
  voice Voice appliance attributes

2. コマンドの省略とエラー指摘

◆ コマンドの短縮入力

Cisco機器では、他のコマンドと区別できる文字数まで入力していれば、省略形でもコマンドが実行されます。本シミュレーターでも完全に再現されています。

  • configure terminal ➔ conf t
  • interface Ethernet0/0 ➔ int e0/0
  • copy running-config startup-config ➔ copy run start

◆ エラーマーカー（^）による位置指摘

コマンドの綴りやオプションを間違えた場合、無効な単語のすぐ下に ^ マーカーが表示され、どこが間違っているかを正確に指摘してくれます。

Switch(config-if)# switchport mode acces
                                ^
% Invalid input detected at '^' marker.

3. ターミナル操作の小技

  • 履歴の呼び出し: ↑（上矢印）キーを押すと、過去に入力したコマンドを遡って呼び出すことができます。何度も同じコマンドを打つ際に便利です。
  • カーソル移動: 入力済みの長いコマンドの一部だけを直したい場合、← → キーでカーソルを移動させて途中の文字を編集できます。

4. 【重要】設定の保存について

課題（シナリオ）モードをプレイしている場合、設定変更後に「設定の保存」を行わないと、正解判定になりません。
実機において再起動後も設定を残すための重要な手順です。すべての設定が完了したら、特権EXECモード（#）に戻り、以下のいずれかのコマンドを必ず実行してください。

Router# copy running-config startup-config
Destination filename [startup-config]? (Enterを押す)
Building configuration...
[OK]

※短縮形の copy run start や、古い表記である write (または wr) でも保存可能です。
